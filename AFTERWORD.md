# Afterword (a personal opinion)

This document is a space for the project author's own personal thoughts. What follows is not the project's official position, just one person's opinion, and it's separate from the technical content in the README or anywhere else.

## On making reverse engineering public

I personally have mixed feelings about reverse engineering being practiced out in the open. The technique exists, at its core, to restore products whose original designs have been lost. But if someone copies a commercial product's technology almost exactly and ships it for free, what does that leave the commercial products that were built up carefully, piece by piece, from nothing?

Thinking it over more, though, the real problem isn't reverse engineering as a capability. It's the specific bad-faith use of that capability. A tool like REA feels a lot like a gun. What it gets used for depends entirely on who's holding it. Someone with bad intentions could use it to reverse engineer things far more easily than before. What I'm actually worried about isn't reverse engineering itself, it's the possibility that REA getting this much attention also pulls in more people who want to use it that way.

That said, I still don't want open source culture to disappear. It gives developers and ordinary users alike a chance to run into new ideas, and human creativity doesn't run out. dnSpy, which I actually use myself, is a good example of that.

So what I actually wanted to do with this project wasn't spread the capability to reverse engineer things further. It was to measure how well the defenses against that capability actually hold up, and publish the results honestly either way.
